基本编辑功能
======

Key            Function           Description
---            --------           -----------
Enter          AcceptLine         接受输入或移到下一行(如果输入缺少结束标记)。
Shift+Enter    AddLine            将光标移到下一行，而不尝试执行输入
Ctrl+h         BackwardDeleteChar 删除光标前的字符
Backspace      BackwardDeleteChar 删除光标前的字符
Ctrl+Home      BackwardDeleteLine 删除从光标处到行开头的文本
Ctrl+Backspace BackwardKillWord   将从当前单词或前一单词开头到光标处的文本移到剪切环


光标移动功能
======

Key            Function        Description
---            --------        -----------
Ctrl+LeftArrow BackwardWord    将光标移到当前单词或前一单词的开头
Home           BeginningOfLine 将光标移到行的开头


基本编辑功能
======

Key    Function         Description
---    --------         -----------
Ctrl+c CopyOrCancelLine 将所选文本复制到剪贴板，或者如果没有选定文本，则使用 CancelLine 取消对行的编辑。
Delete DeleteChar       删除光标下的字符


光标移动功能
======

Key Function  Description
--- --------  -----------
End EndOfLine 将光标移到行尾


基本编辑功能
======

Key              Function          Description
---              --------          -----------
Ctrl+End         ForwardDeleteLine 删除从光标到行尾处的文本
Ctrl+Enter       InsertLineAbove   在当前行上面插入新的空行，而不尝试执行输入
Shift+Ctrl+Enter InsertLineBelow   在当前行下面插入新的空行，而不尝试执行输入
Ctrl+Delete      KillWord          将从光标到当前单词或下一单词末尾处的文本移到剪切环


光标移动功能
======

Key             Function Description
---             -------- -----------
Ctrl+RightArrow NextWord 将光标前移到下一单词的开头


基本编辑功能
======

Key    Function   Description
---    --------   -----------
Escape RevertLine 等同于撤消所有编辑操作(清除相关行，从历史记录中导入的行除外)


其他功能
====

Key           Function              Description
---           --------              -----------
Ctrl+PageDown ScrollDisplayDownLine 将显示向下滚动一行
Ctrl+PageUp   ScrollDisplayUpLine   将显示向上滚动一行


选择功能
====

Key                   Function            Description
---                   --------            -----------
Shift+Home            SelectBackwardsLine 调整当前选择内容，使之包括从光标至行尾的文本
Shift+Ctrl+LeftArrow  SelectBackwardWord  调整当前选择内容，使之包括上一单词
Shift+End             SelectLine          调整当前选择内容，使之包括从光标至行的开头的文本
Shift+Ctrl+RightArrow SelectNextWord      调整当前选择内容，使之包括下一单词
